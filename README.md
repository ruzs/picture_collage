# 圖單拼接 (Square Tile Stitcher)

一個純前端的正方形圖片複製、獨立旋轉與自由網格拼接工具。使用者只需上傳一張正方形圖片，即可自由複製多個區塊、為每個區塊獨立設定旋轉角度，並按照自訂的欄列數與排列方向拼接匯出為高畫質 PNG 圖片。

---

## ✨ 功能特色

- **純前端本地處理**：所有圖片讀取、旋轉與 Canvas 繪製皆在瀏覽器本地端完成，**圖片不會上傳至任何伺服器**，確保隱私與安全性。
- **拖拽與即時驗證**：支援點擊選擇或直接拖曳上傳 `JPG`、`PNG`、`WEBP` 格式，並自動檢查圖片是否為正方形（寬度 $=$ 高度）。
- **獨立區塊編輯**：
  - 支援單張複製（連同當前旋轉角度一併複製）或批次新增多個區塊（上限 100 張）。
  - 每個區塊皆可獨立設定 `0°`、`90°`、`180°`、`270°` 旋轉角度，並提供即時預覽。
  - 支援隨時調整區塊前後順序或刪除特定區塊。
  - 更換原始圖片時，可保留現有的區塊數量與角度設定，方便快速替換素材。
- **彈性網格拼接**：
  - 自訂水平每列張數（欄數），系統自動計算垂直列數。
  - 支援 **水平優先**（由左至右）與 **垂直優先**（由上至下）兩種排列方向，輕鬆組合出純水平長條、純垂直長條或多行多列無縫拼貼圖（如磁磚紋理、對稱圖騰）。
- **原尺寸無損匯出**：依據原始圖片像素尺寸等比例拼接，一鍵下載 `stitched-image.png`。

## 🚀 快速開始

本專案為純靜態網頁，無需安裝 Node.js 或任何後端環境即可執行：

1. **複製專案至本地**
   ```bash
   git clone https://github.com/你的帳號/你的專案名稱.git
   cd 你的專案名稱
   ```

2. **確認依賴檔案**
   請確保 `dist/` 資料夾內包含 `bootstrap.min.css`、`bootstrap.bundle.min.js` 與 `jquery-4.1.0.min.js`。

3. **開啟網頁**
   - 直接使用瀏覽器雙擊開啟 `index.html`。
   - 或使用 VS Code 的 **Live Server** 擴充套件啟動本地伺服器。

## 📖 使用說明

1. **上傳圖片**：點擊上傳框或將一張正方形圖片（寬高相等）拖曳至虛線區域內。
2. **調整區塊**：
   - 預設會建立 2 個相同區塊，你可以點擊右上方的「＋ 加入複製」批次新增，或點擊單張卡片上的「複製」按鈕。
   - 點擊卡片下方的 `0°`、`90°`、`180°`、`270°` 調整該區塊的旋轉方向。
   - 使用 `←` 與 `→` 調整區塊的排序位置。
3. **設定拼接網格**：
   - 輸入 **水平每列張數（欄數）**（例如輸入 `2` 搭配 4 個區塊，將組成 $2 \times 2$ 的四宮格）。
   - 選擇 **排列順序方向**（水平優先或垂直優先）。
4. **產生與下載**：點擊「開始拼接圖片」預覽最終結果，確認無誤後點擊「下載拼接圖片」即可儲存。

## 🛠️ 使用技術

- **HTML5 Canvas API**：用於精準計算旋轉矩陣並繪製高解析度拼接圖。
- **Bootstrap 5.3.9**：建構響應式卡片介面與操作元件。
- **jQuery 4.1.0**：處理 DOM 動態渲染、狀態管理與拖曳事件。
